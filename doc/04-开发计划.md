# 开发计划（逐步开发）

## 协作节奏（老板定的）

- 老板逐步指导，**方向未确认不写下一步**
- 每步完成后交付可测产物（exe / 页面），老板实测反馈再继续
- 修改文件必须汇报；删除/大幅修改前先问
- 只做当前步骤范围内的事，不越权（教训：2026-09-01 一次越权开发被叫停）
- 老板对 Go 不熟（2026-09-06 定）：每步代码写完后**边讲边交付**，讲清这段 Go 干嘛，老板审 + 学，确认再下一步
