# 架构设计

## 运行形态

```
浏览器 → http://127.0.0.1:18765
          ├─ /api/*    → Go 后端
          └─ /         → 内嵌前端页面（web/dist）
```

- 端口固定 18765（config.json 可改）；监听失败 = 已有实例在跑 → 直接开浏览器复用旧实例
- 工作目录 = exe 所在目录，数据/配置生成在 exe 旁

## 目录结构（规划）

```
file-ledger/
├── main.go              入口：配置加载、启动服务、开浏览器
├── config.json          运行配置（exe 旁）
├── internal/
│   ├── registry/        台账模型 + PostgreSQL 存储（CRUD、parent_id 层级、校验）
│   ├── fsx/             路径解析、防穿越、目录列举、可达性检测（步骤 4）
│   ├── api/             REST 处理器 + 路由 + 请求日志中间件（rid）
│   ├── db/              自动建库建表（schema.sql 幂等执行，go:embed）
│   └── logx/            结构化日志（级别 + key=value + rid 追踪，零第三方）
├── web/                 Vue3 前端工程
│   ├── src/             （App.vue 等）
│   └── dist/            构建产物（go:embed 嵌入）
├── doc/                 文档
└── .github/workflows/   钉钉通知
```

## API 边界（REST）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/registry | 台账全量（前端组树；含 parentId） |
| POST | /api/registry | 新增（UUID 服务端生成；校验：别名唯一、父条目存在、类型合法、文件必填路径） |
| PUT | /api/registry/{id} | 更新（path 参数为 UUID；parentId 可改=移动位置） |
| DELETE | /api/registry/{id} | 删除（级联删除子条目） |
| GET | /api/config | 配置（default_drive） |
| GET | /api/fs/list?alias=x&path=rel | 目录列举（文件夹在前，名称排序） |
| GET | /api/fs/status?alias=x | 可达性检测（存在/可读/虚拟仅记录） |

错误统一返回 `{"error": "中文消息"}`，前端直接展示。

## 数据模型（台账 Entry）

| 字段 | 说明 | 约束 |
|---|---|---|
| id | 主键 | UUID v7，服务端生成，天然按时间排序 |
| alias | 别名 | 必填、唯一、排序键 |
| type | local / mount / virtual | 必填 |
| root | 根路径 | local/mount 必填（mount 如 `Z:`） |
| rel_path | 虚拟路径 | virtual 必填（如 `game/rpg`） |
| jump_url | 跳转链接 | virtual 可选 |
| note | 备注 | 可选 |
| tags | 标签 | jsonb 数组（可选），实现标签筛选 |
| read_only | 只读锁 | 预留 |
| created_at / updated_at | 时间戳 | 服务端维护 |

存储：PostgreSQL，`registry` 表；`pgx/v5` 驱动，纯 Go 零 CGO。连接池由 pgx 原生管理。

## 配置 config.json

| 字段 | 默认值 | 说明 |
|---|---|---|
| host | 127.0.0.1 | 只监听本机 |
| port | 18765 | 端口被占 = 复用已有实例 |
| default_drive | "Z:" | 挂载盘符默认值 |
| dsn | postgres://127.0.0.1:5432/file_ledger?sslmode=disable | 数据库连接串 |
| thumb_cache | data/thumbs | 缩略图缓存（批次 2） |
| open_browser | true | 启动自动开浏览器 |

## 安全设计

- **防路径穿越**（批次 1 必做）：root 白名单 + `filepath.Clean`/`Rel` 前缀校验，拦截 `../`、绝对路径
- 服务只监听 127.0.0.1，不暴露外网
- 符号链接逃逸检测：后续批次加固（TODO）
- PostgreSQL 监听 127.0.0.1 不对外暴露

## 关键决策记录

- 虚拟路径不碰文件系统：查台账直接返回「仅记录」，不做 fs 操作
- 盘符状态：`os.Stat` 判定，Linux 自测时用普通路径模拟，Windows 需实测
- 缩略图：Go 纯库生成 + 缓存目录 + 过期清理（批次 2 细化）
- 数据库选型：老板本地已有 PgSQL 实例（2026-09-13 确认），使用 pgx 驱动
