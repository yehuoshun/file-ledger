# 需求说明 v1.0（2026-09-01 定版）

## 目标

Windows 本地工具：统一管理常用路径（本地目录 / 挂载盘符 / 网盘等第三方路径指向），浏览文件、查看图片。

## 核心需求

- **路径台账**：每条路径有「别名 + 类型」，集中管理，像收藏夹一样。
- **Windows 式文件夹树（2026-10-05 补充定版）**：虚拟文件夹 = 系统内逻辑分类容器（无实体），把散乱的本地/挂载/网盘路径归拢管理；层级用 parent_id 自引用（NULL=顶层），文件夹可嵌套、子条目跟随父移动、删除级联子条目；文件夹允许无路径（纯分类），文件必填路径。
- **三类路径**：

| 类型 | 说明 | 能力 |
|---|---|---|
| `local` | 本地目录（如 `D:\games`） | 浏览 + 预览 |
| `mount` | 挂载盘符（默认 `Z:`，可配置） | 浏览 + 预览；盘符在线显示可达，离线标不可达，不崩溃 |
| `virtual` | 虚拟路径，指向网盘等远程路径（如 `ali:game/rpg`） | 仅记录 + 复制路径 + 跳转链接 |

- **挂载盘符可配置**：`config.json` 的 `default_drive`（默认 `Z:`），表单占位提示用。
- **不直接对接网盘 API**：不鉴权、不拉取、不路由，只保存路径指向。

## 使用场景

- `ali:game/rpg` → 网盘目录只记录，双击复制路径 / 打开跳转链接
- `Z:\` → 浏览挂载盘内容（盘符在线/离线状态需 Windows 实测）

## 交互要求

- 双击 exe 自动起服务并打开浏览器（端口 18765）
- 二次双击不重复起服务，直接复用已有实例
- 单机使用，监听 127.0.0.1

## 明确不做（当前阶段）

- 网盘 API 集成（阿里云盘/百度网盘等 SDK）
- 文件上传/传输/同步
- 多用户、权限体系
- 桌面原生壳（托盘/右键集成）——非刚需，快捷方式/开机自启足够
