# file-ledger 文件台账管理工具

Windows 本地工具：统一管理「本地目录 / 挂载盘符 / 虚拟路径」三类路径的记录与浏览。

## 功能规划

- **台账**：为常用路径定义别名（如 `z:` 挂载盘、`games` 本地目录），统一管理
- **本地/挂载路径**：浏览目录、图片预览
- **虚拟路径**：仅记录网盘等远程路径指向（如 `ali:game/rpg`），支持复制/跳转
- 挂载盘符可配置（默认 `Z:`）

## 技术栈

- 后端：Go（单二进制，Windows 直跑）
- 前端：Vue3 + Element Plus（本地 Web UI，启动自动开浏览器）
- 数据：本地 JSON 台账（exe 旁 data/ 目录）
